# Pasiv

Passive, simple income: a one-button, non-custodial miner for the computers
you already own. The pool pays your wallet directly — Pasiv never holds funds.

**The code that touches money is open source.** The 4%% fee engine, its
enforcement, the coin/pool roster, the payout validators, and the complete
headless daemon are GPLv3 at [pasiv-core](https://github.com/hash-rate/pasiv-core)
— every release is built against a pinned, auditable revision of it.

- Website: https://pasiv.network
- Install: https://pasiv.network/install
- The binding fee commitments: [docs/FEES.md](https://github.com/hash-rate/pasiv-core/blob/main/docs/FEES.md)
- Downloads + auto-update channel: [pasiv-releases](https://github.com/hash-rate/pasiv-releases)
